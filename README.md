# Přísaha — plugin pro Claude

Plugin **Přísaha — asistent** propojí Claude s aplikací Přísaha: podklady, vlastní AI tým a nácvik rozhovoru.
Funguje jen s účtem v aplikaci Přísaha; přihlásíte se při připojení. Repozitář neobsahuje žádná data aplikace.
Přidání v Claude: Přizpůsobit → Pluginy → Přidat → Přidat marketplace → Z repozitáře, adresa `VladimirSenflokBrasty/prisaha-claude`.
V Claude Code: `/plugin install prisaha-asistent --marketplace VladimirSenflokBrasty/prisaha-claude`.
Aplikace: https://prisaha.senflokovi.cz
